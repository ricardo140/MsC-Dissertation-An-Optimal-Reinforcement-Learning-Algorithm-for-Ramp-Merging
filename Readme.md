
All the code is structured as follows:
- Background folder contains the code related to the background RL learning and is structured by the algorithm being applied, QL, DQN and A2C. Each of them contains the implementation for each of the environments proposed, along with a readme file for each of the algorithms.
- The PPO folder contains 2 folders of the code implementation of the PPO algorithm to the 2 environments proposed, these are executed as usual .py files.
- The PPO-Slot-based folder contains 4 items, the PPO implementation using jupyter, the environment desgined called traffic_env_working_cars.py with all 4 different environments, the agent trained and tested in the dissertation called actor_critic_gru_cars_480-510.pt and the readme file.
