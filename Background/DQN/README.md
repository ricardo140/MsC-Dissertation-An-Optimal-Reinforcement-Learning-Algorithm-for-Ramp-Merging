This folder contains the DQN implementation for both of the environments, there are 2 Python files for each of the environments. 

The training file which is called Environment_DQN.py and the testing file which is called Environment_DQN_Test.py. 

Also the agents trained and tested are provided along with some figures and videos of their performance. In order to execute these files, just need to be executed as a usual .py file, no need to pass any arguments or values.
